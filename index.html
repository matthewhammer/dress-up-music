Messed Up Dress Up: every tune, run by run

Every tune in Messed Up Dress Up, at each run of the archive: at its default settings, one loop each, as an MP3. There is one copy of each tune, music/<tune>.mp3: a run records only the tunes that changed, and every run writes the same paths, so only the newest is on this site. Each earlier run is a git tag, which the music player reads. 🖼️ The pictures.
